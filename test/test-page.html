📅 캘린더 테스트 페이지

백엔드 API 없이 프론트엔드를 테스트할 수 있는 페이지입니다.

⚠️ Mock API 서버 실행 필요
테스트를 시작하기 전에 test/mock-api-server.js를 실행해야 합니다.
터미널에서: cd test && npm install && npm start

1. 빠른 테스트 링크

🌡️ 기온 캘린더 (서울, 9월) 🌧️ 강수량 캘린더 (서울, 9월) ⚠️ 경보특보 캘린더 (서울, 9월)

2. 커스텀 테스트

3. 테스트 체크리스트

  • ✅ URL에 region_code와 month 파라미터가 있는지 확인
  • ✅ 캘린더가 정상적으로 로드되는지 확인
  • ✅ API 호출이 성공하는지 (브라우저 개발자 도구 Network 탭)
  • ✅ 탭 버튼 클릭 시 다른 캘린더로 이동하는지 확인
  • ✅ 월 변경 시 URL이 업데이트되고 데이터가 다시 로드되는지 확인
  • ✅ region_code 없이 접속 시 에러 메시지가 표시되는지 확인

4. API 엔드포인트 테스트

다음 링크들을 클릭하여 API 응답을 직접 확인할 수 있습니다:

GET /api/temp-calendar GET /api/rain-calendar GET /api/alert-calendar
